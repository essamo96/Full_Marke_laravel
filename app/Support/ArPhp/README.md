# Arabic PDF support (Ar-PHP subset)

This folder contains a minimal subset of [khaled-alshamaa/ar-php](https://github.com/khaled-alshamaa/ar-php) (LGPL-3.0)
used for DomPDF Arabic glyph shaping:

- `Arabic.php`
- `SarahSpell.php` (required by `Arabic` constructor)
- `data/ar_glyphs.json`

Used by `App\Support\ArabicPdf`.
